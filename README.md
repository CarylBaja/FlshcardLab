# Lab 1: Flashcard App

Android Kotlin flashcard application for the CodePath Lab 1 assignment.

## Required tasks
- [x] Create an Android Studio Empty Activity project
- [x] Display a question in a `TextView`
- [x] Display an answer in a second `TextView`
- [x] Reveal the answer when the question is tapped
- [ ] Push this project to your own GitHub repository

## Optional tasks
- [x] Toggle between the question and answer on tap
- [x] Style both sides with distinct backgrounds and text colors
- [x] Add rounded corners, colored borders, and elevation
- [x] Add three multiple-choice answer views
- [x] Show green for correct answers and red for incorrect answers
- [x] Add a button to show/hide answer choices

## Demonstration
Question: Who is the 44th President of the United States?
Answer: Barack Obama

Tap the question to reveal the answer, and tap the answer to return to the question. Tap any of the three choices to get color feedback. Use the bottom button to hide or show the choices.

## Submission steps
1. Open the folder in Android Studio and let Gradle sync.
2. Run the app on an emulator or Android phone and verify the interactions.
3. Create a GitHub repository and push all project files.
4. Record a GIF showing question-to-answer toggle, multiple-choice feedback, and choice visibility toggle. Save it as `walkthrough.gif` at the repository root.
5. Add `![App walkthrough](walkthrough.gif)` to this README after recording.
6. Submit the GitHub repository URL through CodePath.

**Note:** The GitHub push, emulator verification, and GIF recording must be performed on your machine. They are not completed by this source-code package.
